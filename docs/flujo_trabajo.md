# Flujo de trabajo del proyecto

## Metodología seleccionada

Para el desarrollo del proyecto Sudoku se utilizará **GitHub Flow**, debido a que permite trabajar mediante ramas independientes y realizar la integración de los cambios a través de Pull Requests.

## Flujo de trabajo

El flujo establecido para el proyecto es:

```text
Issue
  ↓
Crear rama
  ↓
Desarrollar funcionalidad
  ↓
Commit
  ↓
Push
  ↓
Pull Request
  ↓
Code Review
  ↓
Aprobación
  ↓
Merge a main
